## Issues found and corrected

The first evidence test run passed 12 of 13 tests and failed the seeded-defect assertion. A child Node test process inherited the parent's `NODE_TEST_CONTEXT` transport and returned an apparent success despite the fixture defect. The harness now removes that test-runner transport only from the child process environment and explicitly requests TAP output. Direct reproduction confirmed the null-value defect; subsequent complete runs passed, including the final 14-test suite.

Review also tightened evaluator/source path checks and linked-path rejection, prevented invalid identifier/status findings and malformed YAML errors from echoing sensitive candidate values, and added artifact existence/privacy checks. A failure cannot be hidden as BLOCKED or PASS. A partial record or mismatched inputs cannot produce a native comparison. The dialog template now has a real repeated-contract extraction target rather than an already-shared helper. Generated host instructions reference PROJECT.md instead of duplicating its facts. Git initialization explicitly excludes user-configured templates; global configuration is unchanged.

No host session was launched and no global settings were changed to isolate one. A workspace-contained native runner setup was not established; host authentication caches/logs/session storage may write outside a fixture. Use an authorized session arrangement before running native evaluation.

The result contract checks evidence structure, references, statuses, input matching and heuristic privacy candidates. It cannot authenticate observations or establish whether a human's evidence supports each score. Privacy scans are heuristic. Browser UI quality, real context loss, repeated native behavior and universal host parity remain unverified. No new global policy was invented from these unobserved cases. Use [the evaluation procedure](../evaluation/README.md) and [adoption guide](v2.5-behavioral-reliability.md) for independent scoring; add scenarios only for supported missing requirements or observed failures.
