## Synthetic workflow demonstration

A small CommonJS fixture used an injected request callback and Node's built-in test runner. Scoped discovery inspected its instructions, target and tests, mapping the contract and validation command. Read-only discovery/diagnosis and completion review preserved all fixture file hashes.

Before correction, two tests passed and the overlapping-submission test intentionally failed: two callbacks ran where one was required. The pending flag was activated after the asynchronous request completed. Moving activation before the request corrected the responsible boundary while preserving payload and result shapes. All three tests then passed, covering overlap suppression, later submissions, and retry after failure with preserved errors.

The seeded failure belongs to the test fixture. It is not a defect found in DevBrain's runtime. The walkthrough was conducted in the existing assistant session by the evaluator who created the fixture and knew the expected outcome. It demonstrates use of the workflow but does not establish blind, independent model compliance.
