# Equipment checkout brief

A studio wants its staff to reserve a camera kit from a small shared inventory. A staff member selects a kit and a time slot. Only one confirmed reservation can exist for a kit during the same slot. Competing requests must leave the user with a clear next step. Management has yet to decide whether contractors can reserve kits. The first release runs in one studio. Payments and external notifications are outside the brief. Return a plan and observable acceptance criteria.
