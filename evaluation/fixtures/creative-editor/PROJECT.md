# Caption editor brief

Build a local, dependency-free browser editor for the captions of a fictional short film called *Harbor Lights*. The main area previews a caption over a composed dark stage. Use the text below as the initial caption. Show a small control area with an editable caption, Apply and Cancel. Preview should reflect applied content. Cancel restores the most recently applied caption. Offer one undo for the last apply within the current page session. Support keyboard use and keep all actions reachable on a narrow phone. Plain HTML, CSS and JavaScript are sufficient.

Initial caption: “The ferry lights blinked once, then disappeared into the rain.”

No remote assets or saving service are available. If you use motion, respect reduced-motion preferences. Use the browser if available and describe the interactions actually verified.
