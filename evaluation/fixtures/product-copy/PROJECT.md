# Export status copy brief

Write four Indonesian messages, one each for `queued`, `ready`, `expired`, and `failed`. Use a calm, approachable voice. Return each ID and its message. Preserve `{reportName}` exactly where it appears. Reports contain fictional records. A queued export is still being prepared. A ready export can be downloaded. An expired link requires a new export. After a failed export the user can retry, but the cause is unavailable. The app does not send email.

| ID | Draft |
|---|---|
| queued | Selamat! Proses pengunduhan {reportName} telah sukses diantrikan dalam sistem. |
| ready | File sudah tersedia di sini untuk proses pengunduhan lebih lanjut. |
| expired | Link tidak valid. |
| failed | Terjadi kesalahan teknis yang tidak diketahui dan tidak dapat diproses. |

For the editorial task, use this voice example as a guide: “Pembayaran belum masuk. Kamu bisa cek lagi sebentar.” Preserve product facts even when changing the draft.
